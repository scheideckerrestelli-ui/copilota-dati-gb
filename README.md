# copilota-dati-gb

Dataset delle mappe di Co-Driver. **Non è un indirizzo da distribuire.**

L'app non li scarica da qui: passa dal proxy `https://codriver.pages.dev/mappe/<file>.json`,
che va a prenderli e li ripassa. È voluto: l'indirizzo di questo repo contiene un
cognome, e nel telefono di un tester non ci deve finire.

Formato identico a `copilota-dati`, prodotto dagli stessi script
(`process_fr.py` / `process_gb.py`, modello `copilota-BELGIO.md`).

Perché sta in un repo suo: GitHub Pages pubblica al massimo 1 GB per sito, e
Francia e Gran Bretagna insieme al resto lo sfonderebbero.
